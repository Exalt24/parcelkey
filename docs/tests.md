# What the tests cover

The tests that need PostgreSQL fail when it is missing and never skip. `python tools/pg.py up` starts a `postgis/postgis:16-3.4` container on port 5436 and writes `.env` with random passwords; `python tools/pg.py down` removes it.

## Mutation check

`tests/mutation_check.py` changes one guard at a time in a copy of the code and requires a failing test for each. Two kinds of mutant:

- derived from the syntax tree of 13 modules: comparisons flipped, `and` and `or` swapped, a `not` removed, a condition negated, a guard that ends in `return` or `raise` replaced by `pass`, a call dropped, a returned value turned into `None`, integers moved by one, rule codes emptied;
- 39 named guards, including the ones in SQL: the row level security policy made always true, read side open, write side open, matching other agencies, not forced, not enabled, missing on one table; the column grants; the unit rule, the level rule, the distance rule, the threshold, the tie margin, lower casing, the trunk zero, the rerun guards, the reconcile orphan check, the contact cap, merging on a name.

Results are in [mutation-results.txt](mutation-results.txt). The recorded run set `PARCELKEY_EXAMPLES=15`, so each Hypothesis test drew 15 examples instead of the default 60, and it ran only the tests that cover the mutated module; in the final recorded run every mutant was killed by those tests (1,440 of 1,440: 1,401 from the syntax tree of 13 modules and 39 named guards), so the whole-suite rerun of survivors was never needed. The first pass of the second review left 7 survivors in `normalise.py` and 1 in `evaluate.py`; each got a test and was run again. The third review changed 184 mutant sites of `normalise.py`, and a first run that counted only the generated tables and the corpus replays left 7 survivors there: six got a table row that decides the guard and one needed a fix, because postcode and state written as separate comma parts in the order `2000, NSW` were read as a suburb called 2000; all 7 were killed on the rerun, then the whole definition above was run again from scratch on the final code. `parcelkey/gnaf_codes.py` is data copied from Geoscape and is not mutated. A survivor means a line no test pins: a test is added, the mutant is never deleted. A line that cannot matter carries `# no-mutate: <why>`.
